## Interpretation limits

- One annual held-out transition; intervals condition on the fitted models and observed prevalence and do not capture year-to-year drift, model-selection uncertainty or regional dependence.
- Model configurations were already developed with this test year visible. This is a diagnostic re-evaluation of the existing model, not a new untouched test.
- Historical features are unchanged from main, including current/static snapshots and retrospective records. The separate historical-input audit is not included; these results do not establish leakage-free prospective performance.
- Mean rescaling is not probability calibration. Test outcomes are used only for evaluation, but test-cohort covariates determine the scaling denominator, as in the app.
- Systems missing a next-snapshot outcome are excluded from metrics but retained in the probability-normalization cohort. Attrition may still bias measured performance.
- The five-year conversion 1-(1-p)^5 assumes constant annual risk and has not been validated on five-year outcomes. Report annual probabilities as approximate.
- The app snapshot and its existing headline rank-ensemble metrics are not regenerated by this command. New results refer to this code and these downloaded input versions.

Inputs, file hashes, model settings, library versions and the bootstrap definition are recorded in `data/planner_evaluation.json`; individual held-out predictions are in `data/planner_test_predictions.csv`.

## Reproduce this local evaluation

Use Python 3.12 and the library versions recorded in `data/planner_evaluation.json`. Install the project requirements, download the three risk workbooks listed in `pipeline/fetch_data.py` and run `python -X utf8 pipeline/fetch_extra.py` (UTF-8 is needed for the downloader on Windows). Preserve the committed SAFER and affordability snapshots when reproducing this particular run. Then run:

```text
python -X utf8 pipeline/evaluate_planner.py --bootstrap 1000
python -m pytest tests -q
```

The external sources are mutable; rerunning a download may produce different results. Source hashes and download URLs are retained so that a refreshed result is not confused with the original snapshot. The existing local changes in the separate historical-input branch were not included in this checkout.
